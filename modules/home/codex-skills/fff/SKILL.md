# FFF File Search

For any file search or grep in the current git-indexed directory, use fff MCP tools.

Prefer the `fff` MCP tools for finding files and searching contents when they are available. Fall back to standard local tools such as `rg` when the MCP server is unavailable, not connected, or a direct shell command is more appropriate for the task.
